# 첫길 (masterpiece-firstpath)

첫길 서비스를 개발하는 저장소입니다.

> 첫길이 어떤 서비스인지는 [docs/overview.md](docs/overview.md)에 정리합니다.

## 폴더 구조

| 경로 | 무엇이 들어 있나 |
| --- | --- |
| `README.md` | 이 문서. 저장소 안내 |
| `CLAUDE.md` | Claude가 작업할 때 따르는 규칙과 프로젝트 메모 |
| `CHANGELOG.md` | 버전별로 무엇이 바뀌었는지 기록 |
| `docs/` | 기획, 설계 문서 |
| `docs/decisions/` | 중요한 결정과 그 이유 기록 |
| `.github/` | 이슈와 PR을 쓸 때 쓰는 양식 |

코드 폴더(예: `src/`)는 사용할 기술이 정해지면 추가합니다.

## 작업 흐름

1. **이슈 만들기:** 할 일이나 버그를 GitHub Issues에 적습니다. 양식이 준비되어 있습니다.
2. **브랜치에서 작업:** main에 바로 고치지 않고, 작업용 브랜치를 만들어 거기서 고칩니다.
3. **PR(Pull Request) 열기:** 브랜치의 변경 내용을 main에 합쳐 달라는 요청입니다. 무엇을 왜 바꿨는지 적습니다.
4. **확인 후 머지:** 내용을 확인하고 main에 합칩니다.

## 용어

- **main:** 항상 정상 상태를 유지하는 기본 브랜치
- **브랜치:** main을 건드리지 않고 따로 작업하는 복사본
- **커밋:** 변경 내용을 저장한 기록 한 단위
- **PR:** 브랜치를 main에 합쳐 달라는 요청. 합치기 전에 변경 내용을 검토하는 곳
