# 시안 대비 차이 및 검토 필요 사항 (단계 0~1)

Figma 원본(`node-id=120-764`)은 이 세션에서 로그인 없이 열 수 없어, 동봉된 PNG 11장과 ROADMAP.md를 기준으로 구현했습니다.

## 원본을 보지 못하고 명세로 만든 화면 — 검토 필요
| 화면 | 구현 내용 |
|---|---|
| 홈 `/home` | 진행 중 신청 / 이어쓰기 / 매칭 시작하기 배너, 진행 방식·파일럿 가격, 데일리 2건, 추천 장소 |
| 메뉴 상세 | 장소 상세의 '메뉴' 탭(메뉴명·가격 목록) |
| 매칭 2단계 `/apply/2` | 분위기·음식·데이트 스타일(각 1개 이상 필수)·피하고 싶은 장소(선택). 선택지는 임시안 |
| 제출 전 확인 `/apply/confirm` | 역 최대 2곳, 2주 내 날짜(최대 6일), 시간대 최대 2개, 1인 예산, 공개할 소개 확인 체크 |
| 신청 완료 `/apply/done` | 신청 번호, 운영자 검토 대기, 다음 절차 안내 |
| 인용 게시물(cited) | 후순위로 미구현 (상세 탭에서 숨김) |

## 시안과 의도적으로 달라진 점
- 하단 메뉴: 홈·데일리·큐레이팅·저장·프로필 → **홈·장소·내 약속·저장·프로필** (파일럿 제안, D01 승인 필요). 데일리는 홈에서 진입.
- 장소 카드/상세: 평점·리뷰 수·'영업중' 표시 제거 → 영업시간 텍스트 + **정보 확인일**. 사진은 색 자리표시. 상호는 가상.
- 상세 탭: info/menu/cited/review → **정보/메뉴**만. 지도 이미지 대신 외부 지도 링크(역 기준), 주소 복사.
- 데일리: 사용자 계정·팔로우·좋아요/댓글 수 제거 → '첫, 길 운영팀' 글, 연결 장소 저장, 링크 공유.
- 프로필: 좋아요 수·게시물 그리드 제거 → 실제 저장 수, 신청 상태, 닉네임 수정, 데모 초기화.
- 3단계 만남 템포: '채팅 후 결정' → **'일정 확인 후 결정'** (ROADMAP: 채팅 후순위). 나이 범위 20~45세, 기본 25~35세.
- 다음 버튼: 미완성 시 회색이지만 누를 수 있으며, 누르면 해당 필드에 오류를 표시.
- 상단 알림(종) 아이콘: 알림 기능이 없어 숨김.
- 영문 온보딩(02)·헤더(03)·후기(08): 이번 범위 아님.

## 미확정 가정값
파일럿 역 목록(성수·뚝섬·건대입구·왕십리·서울숲), 시간대 4종, 한 줄 소개 80자·상세 500자, 예산 상한 20만원, 날짜 최대 6일.
